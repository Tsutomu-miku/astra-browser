# Astra App Resources

This directory contains Astra-specific product resources: icons, strings,
images, and other UI assets that are packaged with the browser.

## Chromium Resource Framework

Astra reuses Chromium's resource system (.grd / .grdp files, ` grit`
generator, `ui::ResourceBundle`).  We do not introduce a separate resource
loading system.

- Resources are defined in `.grd` files (GRIT — Google Resource and
  Internationalization Tool).
- Compiled resources are accessed via `ui::ResourceBundle` and `IDR_*`
  constants generated by GRIT.
- Strings use Chromium's l10n system (`.xtb` files, `IDS_*` constants).
- Images use `SkBitmap` / `gfx::ImageSkia` loaded from resource IDs.

Chromium owns: resource loading, GRIT toolchain, `ResourceBundle`, l10n
infrastructure.
Astra owns: product-specific icons, strings, and UI assets.

## Build Integration

Resources are compiled via a `grd` target in GN:

```gn
# TODO(astra): Add this to astra/app/BUILD.gn
grit("astra_resources") {
  source = "astra_resources.grd"
  outputs = [
    "grit/astra_resources.h",
    "grit/astra_resources.cc",
    "astra_resources.pak",
  ]
  deps = [
    "//chrome/app:theme_resources",
  ]
}
```

The resulting `.pak` file is added to the browser's resource bundle at
startup via `ResourceBundle::AddDataPackFromPath()`.

## Conventions

- Icon sizes follow Chromium conventions: 20dp for toolbar/sidebar icons,
  with @2x and @3x variants for high-DPI displays.
- Use vector icons (`.icon` files / SVG) where possible so they scale
  cleanly.  Raster assets are only for photographic content or when
  vector is impractical.
- File naming: `astra_<name>_<size>dp.png` for PNGs,
  `astra_<name>.icon` for vector icons.
- All resources are prefixed with `Astra` / `astra_` to avoid name
  collisions with Chromium's resource namespace.
